My games

Snake

Snake was the very first game I ever coded. I decided to start my programming journey with Python, and for a first project, I think it turned out pretty well! You can play solo or head-to-head with a friend in 2-player mode. The goal is simple: get as many points as possible without crashing.

Jump and Run

For my second game, I wanted to build a project using a 2D editor, so I decided to learn GDScript in Godot. Creating the first level was very interesting, but it eventually became repetitive-it felt less like actual coding and more like placing the exact same elements in the editor over and over again. Despite that, GDScript proved to be a very accessible language.

Blockera

I wanted to start a long-term project, and creating a 2D Minecraft-style sandbox sounded perfect. I chose Java to match the engine of the original game. The best part about a sandbox project is that there's no fixed finish line. I can keep coding and expanding it for as long as I like, or wrap it up whenever I feel it's complete.
